# MIMS XML Normalizer

MIMS XML을 트랙 단위의 표로 정규화하고 검수·편집·복사·내보내기할 수 있는 단일 HTML 기반 로컬 도구입니다.

설치나 서버 실행 없이 `MIMS-XML-Normalizer.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다. 불러온 XML과 생성된 데이터는 외부 서버로 전송되지 않습니다.

## 주요 기능

- MIMS XML 드래그앤드롭 및 파일 선택
- XML namespace를 고려한 앨범·트랙 정보 파싱
- 앨범 공통 정보와 트랙별 메타데이터를 한 행으로 정규화
- UPC, ISRC, MusicUCI 등 식별자를 문자열 그대로 보존
- 곡명, 아티스트, ISRC, UCI 등 전체 필드 검색
- 열 헤더 클릭을 통한 오름차순·내림차순 정렬
- 셀 범위, 행 및 전체 테이블 선택
- 선택 영역 TSV 복사 및 스프레드시트 붙여넣기
- 셀 직접 편집 및 변경 항목 표시
- CSV·TSV 전체 내보내기
- XML 구조와 메타데이터에 대한 자동 QC
- 앨범 요약 및 원본 XML 확인

## QC 항목

다음 항목을 자동으로 검사하고 `Error`, `Warning`, `Info`로 구분해 표시합니다.

- XML 문법 오류 및 필수 구조 누락
- 트랙 번호 중복
- ISRC 누락·중복·형식 이상
- MusicUCI 누락·중복
- UPC 누락·자릿수 이상
- `????` 등 플레이스홀더 값
- 레이블 누락
- 트랙 수와 총 재생 시간

## 사용 방법

1. 저장소에서 `MIMS-XML-Normalizer.html`을 다운로드합니다.
2. 파일을 Chrome, Edge, Safari 또는 Firefox에서 엽니다.
3. MIMS XML 파일을 화면에 드롭하거나 **파일 선택**을 누릅니다.
4. 자동 생성된 테이블과 QC 결과를 확인합니다.
5. 필요한 셀을 선택해 복사하거나 CSV·TSV 파일로 내려받습니다.

별도의 패키지 설치, 빌드, 개발 서버 또는 인터넷 연결은 필요하지 않습니다.

## 선택 및 키보드 조작

| 동작 | 방법 |
| --- | --- |
| 셀 선택 | 셀 클릭 또는 드래그 |
| 범위 확장 | `Shift` + 클릭 또는 `Shift` + 방향키 |
| 행 전체 선택 | 왼쪽 행 번호 클릭 |
| 표시 테이블 전체 선택 | 표 왼쪽 위 모서리 클릭 |
| 선택 영역 복사 | `Ctrl/Cmd + C` |

복사 결과는 탭과 줄바꿈으로 구분된 TSV 형식이므로 Google Sheets와 Microsoft Excel에 바로 붙여넣을 수 있습니다.

## 내보내기

- CSV: UTF-8 BOM을 포함해 한글 호환성을 높였습니다.
- TSV: 탭 구분 텍스트로 저장합니다.
- 식별자: UPC, ISRC, MusicUCI 값을 숫자로 변환하지 않고 원문 문자열로 유지합니다.
- 범위: 현재 검색·정렬 결과 전체를 내려받을 수 있습니다.

## 개인정보 및 보안

모든 XML 파싱과 데이터 처리는 브라우저 안에서 수행됩니다.

- 서버 업로드 없음
- 외부 API 호출 없음
- CDN 및 외부 JavaScript 의존성 없음
- 사용자 계정 및 데이터베이스 없음

브라우저 탭을 닫거나 다른 XML을 열면 현재 편집 내용이 사라질 수 있으므로 필요한 결과는 CSV 또는 TSV로 먼저 저장하세요.

## 현재 범위

현재 버전은 한 번에 하나의 MIMS XML 파일을 처리합니다. XML 원본 재생성, 오디오 파일 대조, DDEX 검증, 여러 XML의 일괄 병합 및 서버 저장 기능은 포함하지 않습니다.
