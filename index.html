사용 가이드
01 · XML 불러오기
MIMS XML 파일을 놓거나 파일 선택을 누르세요. 최대 20MB, 한 번에 한 파일을 처리합니다. 불러오면 트랙 정규화와 QC가 자동으로 실행됩니다.
02 · 검색과 검수
검색창에 곡명, 아티스트, ISRC 또는 UCI를 입력하면 결과가 즉시 필터링됩니다. 열 제목을 클릭하면 정렬됩니다. QC, 앨범 요약, 원본 XML 탭에서 세부 정보를 확인하세요.
03 · 선택과 내보내기
셀을 드래그하거나 Shift+클릭으로 범위를 선택하세요. 행 번호는 행 전체, 표 왼쪽 위 모서리는 전체 데이터를 선택합니다. Ctrl/Cmd+C 또는 선택 복사로 TSV를 복사하고 시트에 붙여넣으세요. CSV·TSV 버튼은 현재 검색 결과 전체를 다운로드합니다.
04 · 편집과 키보드
편집 체크박스를 켜면 셀 내용을 수정할 수 있습니다. 헤더 포함을 켜면 복사 시 열 이름이 함께 들어갑니다. 셀 선택 모드에서는 방향키로 이동하고 Shift+방향키로 범위를 확장합니다.
주의 사항
다른 파일을 열거나 페이지를 닫으면 현재 편집 내용은 사라집니다. 필요한 결과를 먼저 다운로드하세요. 복사가 제한되는 로컬 브라우저 환경에서는 TSV 다운로드를 이용하세요.
기술 정보
단일 HTML · CSS · JavaScript로 동작합니다. 설치, 서버, 외부 라이브러리가 필요하지 않습니다. Pretendard가 설치되어 있으면 사용하고, 없으면 시스템 글꼴로 표시합니다.
